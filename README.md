# DigitalTwin

Unity digital-twin project for the Nema robotic-arm environment.

## Open the project in Unity Hub

1. Open **Unity Hub** and select **Projects**.
2. Click **Add** in the upper-right corner.
3. Select **Add project from disk**.
4. Select this repository root:

   ```text
   C:\Users\USER\Downloads\DigitalTwin_latest
   ```

   Select the folder containing `Assets`, `Packages`, `ProjectSettings`, and
   `UserSettings`. Do not select only the `Assets` or `ProjectSettings` folder.
5. Open the project listed as **DigitalTwin (GitHub latest)**.
6. Use Unity editor version **6000.2.10f1** when Unity Hub asks for an editor.

## Open the main scene

After Unity finishes importing the project:

1. In the Project panel, open `Assets`.
2. Open `Scenes`.
3. Double-click `MainScene`.

The scene file is:

```text
Assets/Scenes/MainScene.unity
```

Press the **Play** button at the top of the Unity Editor to run the scene.

## Safe Mode

If Unity reports compilation errors and offers **Enter Safe Mode** or **Exit Safe
Mode**, choose **Enter Safe Mode** first. Wait for package import and script
compilation to finish, review the Console, and then choose **Exit Safe Mode**.
