# DigitalTwin

## Open in Unity Hub

1. Open **Unity Hub** and go to **Projects**.
2. Click **Add** → **Add project from disk**.
3. Select:

   ```text
   C:\Users\USER\Downloads\DigitalTwin_latest
   ```

   Select the folder containing `Assets`, `Packages`, `ProjectSettings`, and
   `UserSettings`.
4. Open the project with Unity version:

   ```text
   6000.2.10f1
   ```

5. In Unity, open:

   ```text
   Assets/Scenes/MainScene.unity
   ```

6. Press **Play** to run the scene.
